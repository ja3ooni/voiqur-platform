# Plan 13-02: FastAPI Instrumentation and Pipeline Metric Recording

## Objective

Wire the metrics from Plan 13-01 into the running application:
1. Register `prometheus-fastapi-instrumentator` in `create_app()` to expose `GET /metrics`
2. Instrument each pipeline stage (STT, LLM, TTS) with per-stage latency Histograms
3. Instrument flash mode with hit/miss Counters
4. Instrument the fallback chain circuit breaker with Gauge state updates

## Tasks

<read_first>

- `kiro/voiquyr/src/core/metrics.py` — the metrics module created in Plan 13-01
