1. Create src/agents/metrics.py:
```python
from prometheus_client import Counter, Histogram

STT_TRANSCRIPTIONS = Counter(
    'stt_transcriptions_total',
    'Total STT transcriptions',
    ['language', 'status']  # success, error
)

LLM_REQUESTS = Counter(
    'llm_requests_total',
    'Total LLM requests',
    ['model', 'status']
)

TTS_SYNTHESES = Counter(
    'tts_syntheses_total',
    'Total TTS synthesizations',
    ['voice', 'status']
)

PIPELINE_LATENCY = Histogram(
    'voice_pipeline_duration_seconds',
    'Voice pipeline latency',
    ['stage']  # stt, llm, tts
)

def track_stt(duration: float, language: str, success: bool):
    PIPELINE_LATENCY.labels(stage='stt').observe(duration)
    STT_TRANSCRIPTIONS.labels(language=language, status='success' if success else 'error').inc()

def track_llm(duration: float, model: str, success: bool):
    PIPELINE_LATENCY.labels(stage='llm').observe(duration)
    LLM_REQUESTS.labels(model=model, status='success' if success else 'error').inc()

def track_tts(duration: float, voice: str, success: bool):
    PIPELINE_LATENCY.labels(stage='tts').observe(duration)
    TTS_SYNTHESES.labels(voice=voice, status='success' if success else 'error').inc()
```

## Secrets Management

### Overview
All secrets are managed via external-secrets operator syncing from Vault or AWS Secrets Manager.

### Setup

#### 1. Install External Secrets Operator
```bash
helm repo add external-secrets https://charts.external-secrets.io
helm install external-secrets external-secrets/external-secrets \
  --namespace external-secrets \
  --create-namespace
```

#### 2. Configure Secret Store
```yaml
apiVersion: external-secrets.io/v1
kind: ClusterSecretStore
metadata:
  name: vault-gdpr
spec:
  provider:
    vault:
      server: "https://vault.example.com:8200"
      path: "secret"
      version: "2"
      auth:
        kubernetes:
          role: "euvoice-secrets"
```

#### 3. Define External Secrets
```yaml
apiVersion: external-secrets.io/v1
kind: ExternalSecret
metadata:
  name: euvoice-secrets
  namespace: euvoice
spec:
  refreshInterval: 1h
  secretStoreRef:
    name: vault-gdpr
    kind: ClusterSecretStore
  target:
    name: euvoice-platform-secrets
  data:
  - secretKey: JWT_SECRET
    remoteRef:
      key: euvoice/jwt-secret
  - secretKey: DATABASE_URL
    remoteRef:
      key: euvoice/database-url
  # ... all other secrets
```

#### 4. Verify Secret Sync
```bash
kubectl get externalsecret -n euvoice
kubectl describe secret euvoice-platform-secrets -n euvoice
```

### Rotation
- Secrets auto-rotate based on refreshInterval
- Manual sync: `kubectl annotate externalsecret euvoice-secrets external-secrets.io/reconcile-timestamp=$(date +%s)`
```
